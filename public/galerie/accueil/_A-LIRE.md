# Dossier « accueil » — galerie de la page d'accueil

Déposez ici les photos de l'aperçu portfolio de la page d'accueil.
Utilisez EXACTEMENT ces noms de fichiers (en `.jpg`) :

| Fichier attendu          | Contenu                     |
| ------------------------ | --------------------------- |
| `mariage.jpg`            | Photo mise en avant (grande) |
| `portrait.jpg`           | Portrait                    |
| `evenement.jpg`          | Événement                   |
| `textile.jpg`            | Personnalisation textile    |
| `design.jpg`             | Design & infographie        |
| `spot-publicitaire.jpg`  | Spot publicitaire           |
| `agrandissement.jpg`     | Agrandissement              |

➡️ Dès qu'un fichier est déposé avec le bon nom, il remplace automatiquement
l'emplacement « Photo à venir ». Rien d'autre à faire.

> Astuce : format `.jpg`, largeur ~1200 px, sans accents ni espaces dans le nom.
